# MENU DE NAVEGACION DE ADASALON

## Descripcion
AdaSalon utiliza un menu lateral para facilitar la navegacion entre las diferentes pantallas de la aplicacion.

## Componentes del menu
- Encabezado con el nombre AdaSalon.
- Icono de identidad visual.
- Descripcion: Gestion de salon de belleza.
- Opcion Inicio con icono de casa.
- Opcion Clientes con icono de usuarios.
- Opcion Productos con icono de caja.

## Navegacion
- Inicio: /home
- Clientes: /clientes
- Productos: /productos

## Adaptacion
Se utiliza ion-split-pane para adaptar la presentacion del menu a pantallas de mayor tamano.

## Archivos principales
- app.component.html
- app.component.ts
- app.routes.ts

## Funcion de navegacion
El metodo navegar() permite cambiar de pantalla y cerrar el menu despues de seleccionar una opcion.
