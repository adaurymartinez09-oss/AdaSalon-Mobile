# INTERFACES DE ADASALON

## 1. Pantalla principal - Inicio
Presenta el panel principal de AdaSalon.

Componentes:
- Encabezado con el nombre AdaSalon.
- Menú lateral de navegación.
- Resumen de clientes registrados.
- Resumen de productos en inventario.
- Resumen de ventas del día.

Archivos:
- home.page.html
- home.page.ts
- home.page.scss

## 2. Pantalla de clientes
Permite visualizar y administrar los clientes del salón.

Componentes:
- Encabezado de clientes.
- Lista de clientes.
- Nombre y teléfono.
- Acción para eliminar clientes.
- Actualización mediante pull-to-refresh.

Archivos:
- clientes.page.html
- clientes.page.ts
- clientes.page.scss

## 3. Pantalla de productos
Permite visualizar los productos del inventario.

Componentes:
- Catálogo de productos.
- Nombre y categoría.
- Precio y descripción.
- Ampliación de productos mediante pinch-to-zoom.

Archivos:
- productos.page.html
- productos.page.ts
- productos.page.scss
